# SwiftRoute Logistics — Digital Last-Mile Delivery Platform

**ITBT Assignment:** Digital Business App
**Business:** Last-Mile Delivery Platform

## Problem
Customers and business clients lack real-time shipment visibility and delivery performance information.

## Solution
A digital platform for shipment tracking, delivery booking, cost calculation and logistics management.

## Features
- Shipment tracking with live status timeline (try `TRK1025`, `TRK1026`, `TRK1027`, `TRK1028`)
- Delivery booking with validation and reference number
- Delivery cost calculator with transparent breakdown
- Manager dashboard: 6 KPIs, doughnut and bar charts, insights, Today/Week/Month filter
- Contact and enquiry form, Google Maps, email and LinkedIn links
- Responsive design with mobile hamburger menu

## Technology
HTML5, CSS3, vanilla JavaScript, GitHub Pages. No backend, no build step.

## How to Run
Download the folder and double-click `index.html`.

## GitHub Pages Deployment
1. Create a GitHub repository
2. Upload `index.html`, `style.css`, `script.js` and `README.md`
3. Go to **Settings**
4. Select **Pages**
5. Select **Deploy from a branch**
6. Select the **main** branch (root folder)
7. Click **Save**
8. Open the generated GitHub Pages URL
